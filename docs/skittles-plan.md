# Skittles: სამუშაო გეგმა

ჩაბარება: კვირა, 18 ოქტომბერი, 12:00. ტრეკი 02, Multiplayer agentic experiences.

## რას ვაწყობთ

ორი ავტორი, თითო თავისი აგენტით, ერთ ცოცხალ დონეს ცვლის, სანამ მესამე ადამიანი მას თამაშობს. აგენტი კოდს არ წერს, მხოლოდ ოპერაციებს გვთავაზობს. ოთახი ოპერაციებს რიგით იღებს, ვალიდატორი ამოწმებს, გზა ისევ არსებობს თუ არა. თუ ცვლილება დონეს ტეხს, მედიატორი გამოსავლის ვარიანტებს გვთავაზობს, ადამიანი ირჩევს. ყველაფერი ავტორით იწერება და ნებისმიერ ვერსიაზე დაბრუნება შეიძლება.

UI ინგლისურია. Flutter-ის აპი (`app/`) ცალკე დესკტოპის რედაქტორია და ამ გეგმაში არ გამოიყენება.

## გადაწყვეტილებები

- **ერთი ოთახი, ერთი პროცესი.** ოთახი აქტორია: ყველა ცვლილება ერთ რიგში დგას. აგენტის LLM გამოძახება რიგის გარეთ მიმდინარეობს და შედეგი `baseRev`-ით ბრუნდება. თუ ვერსია შეიცვალა, ოპერაციები ახალ მდგომარეობაზე თავიდან მოწმდება.
- **ID-ებს სერვერი ანიჭებს.** აგენტი ახალ ობიექტს ID-ის გარეშე ქმნის. სერვერი ანიჭებს `A1`, `B1`, `M1`, ავტორის ასოთი.
- **რას ნიშნავს „გატეხა“.** ცვლილება დონეს ტეხს, თუ მანამდე დონე გავლადი იყო, მის შემდეგ კი აღარ. ასეთი ცვლილება არ იწერება, სანამ ავტორი გამოსავალს არ აირჩევს.
- **უსაფრთხო მომენტი.** თუ ცვლილება მოთამაშის უჯრას კედლად, ლავად ან დაკეტილ კარად აქცევს, ის ელოდება, სანამ მოთამაშე გადავა.
- **დაბრუნება ლოგს არ შლის.** ძველ ვერსიაზე დაბრუნება ახალი ჩანაწერია. ლოგი მხოლოდ ემატება.
- **აგენტის ძრავა.** API გასაღები არ გვჭირდება. ნაგულისხმევად აგენტი Claude Code CLI-ს იყენებს (`claude -p`, Sonnet, JSON სქემით), რომელიც ამ Mac-ზე შესულ Claude ანგარიშზე მუშაობს. თუ `server/.env`-ში `ANTHROPIC_API_KEY` ჩაიწერება, სერვერი პირდაპირ Claude API-ზე გადადის. `Skittles_AGENT=api|cli` ძრავას იძულებით ირჩევს.
- **გაზომილი შედეგი (21:20).** 10 რეალური მოთხოვნიდან 9 სწორად შესრულდა, ერთი (დრაკონი) სწორად უარყო ახსნით. დრო 3.9–8 წამი, საშუალოდ 5.7. პირველი მოთხოვნა ცივ სტარტზე 10 წამამდეა, ამიტომ დემომდე ერთი მოთხოვნით „ვათბობთ“.
- **დემოს კონფლიქტი ბუნებრივად ხდება.** ნინო: ლავის მდინარე ერთი გასასვლელით. გიორგი: „დიდი ქანდაკება რუკის შუაში“. გიორგის აგენტი თვითონ ამბობს, რომ ქანდაკება ნინოს მდინარის ერთადერთ გასასვლელზე დგება. ოთახი ცვლილებას აჩერებს, მედიატორი ხიდს სთავაზობს, ნინო ამტკიცებს.

## რა დარჩა (22:15-ის მდგომარეობით)

1. სამი სრული რეპეტიცია სამი ადამიანით, Chrome-ში ხმით.

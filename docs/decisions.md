# გადაწყვეტილებები

ყოველი ჩანაწერი მოკლედაა: რა გადავწყვიტეთ, რატომ და რა მოჰყვება. სრული კვლევა და შედარება დოკუმენტის ჩანართშია „აპლიკაციის გეგმა“.

## D1. აპი Flutter-ზე (2026-10-17)

- **გადაწყვეტილება:** Mac-ისა და Windows-ის ვერსიები ერთი Flutter კოდით (Flutter 3.47.7, Dart 3.13.5).
- **რატომ:** ერთი კოდი ორივე პლატფორმისთვის. გადაწყვეტილება გუნდმა მიიღო, მაშინ როცა რეკომენდაცია SwiftUI იყო.
- **რა მოჰყვება:** Liquid Glass-ის ოფიციალური მხარდაჭერა Flutter-ს არ აქვს, ამიტომ ეტაპი 1-ში ორ პაკეტს ვცდით. iOS-ისა და macOS-ის დამოკიდებულებებს Swift Package Manager მართავს, ამიტომ ვიყენებთ მხოლოდ იმ პლაგინებს, რომლებსაც SwiftPM-ის მხარდაჭერა აქვთ.

## D2. მხოლოდ დესკტოპი, ჯერ Mac (2026-10-17)

- **გადაწყვეტილება:** ლეპტოპი და უფრო დიდი ეკრანები. iPad და iPhone არ არის. ფანჯრის მინიმალური ზომაა 1280 × 720.
- **რა მოჰყვება:** მართვა კლავიატურითა და მაუსით ხდება. Play რეჟიმში თითოეული მოთამაშე საკუთარ Mac-ზე თამაშობს.

## D3. სერვერი Node + Socket.IO (2026-10-17)

- **გადაწყვეტილება:** ოთახის ავტორიტეტული სერვერი Node-ზე (TypeScript) და Socket.IO 4.8-ზე.
- **რა მოჰყვება:** სერვერს მუდმივად ჩართული ჰოსტინგი სჭირდება. მონაცემთა ბაზის არჩევა (SQLite ან Postgres) ეტაპ 3-ზეა გადადებული.

## D4. ერთდროული რედაქტირება Figma-ს მოდელით

- **გადაწყვეტილება:** სერვერი ცვლილებების თანმიმდევრობას განსაზღვრავს. კონფლიქტი თვისების დონეზე წყდება: ბოლო ჩაწერილი იმარჯვებს. CRDT ბიბლიოთეკა არ გვჭირდება.
- **სადაა:** `spec/protocol.md`.

## D5. ერთი სპეციფიკაცია, ერთი ტესტების ნაკრები

- **გადაწყვეტილება:** თამაშის წესები `spec/rules.md`-შია. ორივე იმპლემენტაცია (სერვერი TypeScript-ზე, აპი Dart-ზე) `spec/fixtures/`-ის ერთსა და იმავე ტესტებს გადის.
- **რატომ:** წესები ორ ენაზე იქნება დაწერილი. ტესტები გვიცავს იმისგან, რომ ორმა იმპლემენტაციამ სხვადასხვანაირად იმუშაოს.

## D6. ერთი სახელი: Skittles (2026-10-17)

- **გადაწყვეტილება:** პროექტს, რეპოზიტორიას, სერვერს, ვებ კლიენტს და Flutter-ის აპს ერთი სახელი აქვს, Skittles. ძველი სახელები LIVEFORGE და Ertad აღარ გამოიყენება.
- **რა მოჰყვება:** გარემოს ცვლადები ახლა `SKITTLES_`-ით იწყება, მაგალითად `SKITTLES_AGENT`. Skittles Mars-ის კანფეტის სავაჭრო ნიშანიცაა, ამიტომ ჰაკათონის მიღმა გამოყენებამდე სახელი უნდა შემოწმდეს.

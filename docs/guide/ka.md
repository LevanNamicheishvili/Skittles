# რა არის Skittles

Skittles ცოცხალი ოთახია, სადაც გუნდი ერთ სათამაშო სამყაროს ერთად აშენებს. თითოეული ადამიანი საკუთარ AI აგენტს უბრალო სიტყვებით ელაპარაკება, ტექსტით ან ხმით, ქართულად ან ინგლისურად. ყველა აგენტი ხედავს, რა შეცვალეს სხვებმა, სოლვერი ყოველ ცვლილებას ამოწმებს, სანამ ის ცოცხლად ჩაჯდება, და ვიღაცას შეუძლია სამყარო ითამაშოს, სანამ ის იცვლება.

## რა პრობლემას წყვეტს

ბაიტების სინქრონიზაცია ადამიანებს შორის გადაწყვეტილია: Figma, Google Docs და CRDT ამას კარგად აკეთებენ. **განზრახვის** სინქრონიზაცია არ არის გადაწყვეტილი. როცა რამდენიმე ადამიანი ერთ ნამუშევარს საკუთარი აგენტით ცვლის, საშიში კონფლიქტი იშვიათად არის ორი ცვლილება ერთ ხაზზე. საშიშია ორი ცვლილება, რომელიც ცალ-ცალკე სწორია, ერთად კი მიზანს ტეხს.

Git აქ კონფლიქტს ვერ ხედავს, ვერც CRDT: ორი ცვლილება ერთსა და იმავე ბაიტებს არ ეხება. Skittles ხედავს, რადგან სათამაშო დონეში კითხვაზე „მიზანი ისევ მიიღწევა?“ მანქანას შეუძლია უპასუხოს, მილიწამზე ბევრად სწრაფად.

## რა ხდება ამის ნაცვლად

1. ცვლილება, რომელიც დონეს გატეხდა, ჩერდება. ცოცხლად არაფერი ჯდება.
2. დაფა აჩვენებს, სად წყდება გზა, და ასახელებს, ვინ რა ჩაკეტა.
3. მედიატორი სთავაზობს გამოსავლებს, რომლებიც სოლვერმა უკვე შეამოწმა, მაგალითად ხიდს.
4. იმ ავტორის აგენტი, ვისი ნამუშევარიც გზაზე დგას, კომპრომისს სთავაზობს.
5. გადაწყვეტილებას ადამიანები იღებენ. თუ გამოსავალი ვინმეს ნამუშევარს ეხება, მისი თანხმობაა საჭირო.

## ვისთვისაა

- **შემქმნელებისთვის**, რამდენიც გინდა, რომლებიც ერთად აშენებენ, თითოეული საკუთარი აგენტით.
- **ტესტერებისთვის**, რომლებიც სამყაროს თამაშობენ, სანამ ის იცვლება, და პრობლემას თამაშის შიგნიდან აგზავნიან.
- **წამყვანებისთვის**, რომლებიც მთელ ოთახს პროექტორზე აჩვენებენ.

# შეზღუდვები და კითხვები

## გულწრფელი შეზღუდვები

- დემოს საწყისი დონე წინასწარაა მომზადებული. ამის შემდეგ ყველა ცვლილება ცოცხლად გენერირდება.
- აგენტები დეტერმინისტული არ არის. ერთი და იგივე სიტყვები ოდნავ განსხვავებულ დონეს იძლევა, ზოგჯერ კი აგენტი კონფლიქტს თვითონ არიდებს თავს.
- v1-ში არის კედლები, ლავა, ხიდები, ციხეები, კარები, გასაღებები, განძი, მონეტები, სტარტი და დროშა. მტრები და ფიზიკა არ არის.
- აგენტებს ინტერნეტი სჭირდებათ. პირველ მოთხოვნას გაშვების შემდეგ დაახლოებით 10 წამი სჭირდება, შემდეგებს 4-დან 8 წამამდე, საშუალოდ 5.7.
- ერთი სერვერი ერთ ოთახს ამუშავებს და დონე მეხსიერებაში ინახება: სერვერის რესტარტი ყველაფერს თავიდან იწყებს.
- ადამიანები ოთახის სიაში რჩებიან ფანჯრის დახურვის შემდეგაც, სერვერის რესტარტამდე.
- ხმოვან შეყვანას Chrome ან Edge სჭირდება.

**აგენტები კოდს წერენ?**
არა. ისინი ოპერაციებს წერენ, ოთახი კი თითოეულს ამოწმებს.
